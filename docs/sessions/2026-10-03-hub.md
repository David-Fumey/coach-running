# Session du 3 octobre 2026 : validation du plan et hub

## Décisions

- Après la création, le plan passe par un écran de **relecture** (durée, nombre de séances, total de km, phases, profil de volume) ; « Valider mon plan » ouvre le hub, « Modifier mes réponses » revient au formulaire.
- Le hub a une barre d'onglets : Accueil, Programme, Activités, Progrès, Nutrition.
- Une **activité** (date, distance, durée, ressenti, note) peut être liée à une séance du plan, qui est alors marquée faite, ou être une sortie libre. Supprimer l'activité décoche la séance si plus aucune activité n'y est liée.
- Valider une séance dans le Programme (case à cocher) reste possible sans saisir d'activité ; ces séances comptent dans la « régularité » mais pas dans les km/allures.

## Ce qui a été fait

- `src/lib/activities.ts` : type `Activity`, totaux par semaine, résumé (km, temps, allure moyenne, plus longue sortie, régularité). `src/lib/format.ts` : formats communs (km, dates, durée, allure).
- Écrans : `PlanReview`, `Home` (prochaine séance, semaine en cours, chiffres), `PlanView` (devenu l'onglet Programme), `Activities` (liste + formulaire), `Progress` (6 chiffres, km courus/prévus par semaine, évolution de l'allure), `Nutrition` (page « bientôt »), `TabBar`.
- Nouvelles clés `localStorage` : `foulee.activities.v1`, `foulee.confirmed.v1`.
- Vérifié : `tsc`, `npm run build`, `npm run test:plan`, et parcours dans le navigateur (création, relecture, validation, enregistrement d'une activité liée, onglet Progrès).

## Points ouverts

- Un plan créé avant cette version (sans `foulee.confirmed.v1`) repasse une fois par l'écran de relecture.
- Les activités datées avant le début du plan comptent dans les totaux mais pas dans le graphique par semaine.
- Pas d'import GPX/Strava : les activités se saisissent à la main.
- Vérifié uniquement en sombre et à largeur de bureau ; à regarder sur téléphone.

## Prochaines étapes possibles

1. Nutrition : besoins selon la charge de la semaine (les km courus sont maintenant disponibles), journal alimentaire.
2. Conseils selon la phase du plan.
3. Allures cibles, import GPX/Strava.

## Ajout en fin de session

- Modification d'une activité (bouton « Modifier » dans la liste) ; changer ou retirer la séance liée met à jour les séances cochées.
- La logique d'ajout, de modification et de suppression est dans `src/lib/activities.ts` (`addActivity`, `updateActivity`, `removeActivity`, `parseMinutes`) et couverte par `npm run test:activities` (17 vérifications).
